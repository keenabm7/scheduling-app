# UTHC Ulluriaq — Scheduling App

This repository contains the complete developer handoff package for the 
Ulluriaq Adolescent Center scheduling application.

## Live interactive prototype
Click the link below to open and click through the full prototype — 
no download needed, works on phone or computer:

https://claude.ai/artifact/NaCK1Mj3exjsN87CGXeDd8

## Files in this repository
- FEATURE_SPEC.md — Complete written specification (20 sections, 
  all rules, workflows, and permissions)
- uthc-prototype.zip — All clickable HTML prototype files + README 
  explaining what is and isn't covered

## For developers
